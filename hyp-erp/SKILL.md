# 霍普 ERP

将用户提供的差旅票据整理为可核对的报销表单，保留在用户的 Chrome 中，由用户本人检查并提交。

## 固定设置

- 网站：<https://erp.hyp-arch.com/#main>。该地址可能显示登录页，也可能显示已登录首页，以实际页面为准。
- 浏览器：用户的 Google Chrome，使用其已有登录状态或浏览器自动填充。
- 财务入口：`my hyp → 我的财务 → 项目差旅报销`。
- 归属公司：`上海霍普建筑规划设计有限公司`。
- 收款人：`马腾宇`。如出现多个同名记录，结合当前用户已有信息核实。
- 完成方式：填好可确认的内容，核对金额和附件，提醒用户接手提交。保留当前表单；最终提交由用户本人操作。

## 连接与登录

1. 使用已安装的 `chrome:control-chrome` 技能，先读它的 `SKILL.md`，按当前版本文档连接 Chrome。复用本会话中仍有效的浏览器连接。工具接口、初始化路径和上传方式从该技能获取。
2. 优先接管已有的霍普 ERP 标签页。页面上如有进行中的表单，先读取其状态，避免导航或刷新丢失已填内容。没有相关标签页时才打开上述网站。
3. 已进入系统就继续；出现登录页且浏览器已填好账号密码时，直接点击页面上的“登录”。通过页面状态或脱敏截图判断自动填充是否就绪，不读取密码、Cookie 或浏览器凭据存储。
4. 若账号或密码未填、自动填充不可用或登录失败，提示用户在 Chrome 页面内填写或检查，完成后告知，再继续。验证码等需要用户处理的步骤也保留页面交接。无需用户在聊天中提供密码。
5. 点击后核对页面已出现登录后的导航或首页内容，再进入业务流程。连接失败时按 Chrome 技能排查，说明哪些页面尚未核实；不能声称已完成页面验证。

## 项目差旅报销

执行时读取 [项目差旅报销流程](references/travel-reimbursement.md)。每次报销由用户提供一个文件夹，一个文件夹代表一次完整出差的全部票据与证明。先确认文件夹可读并列出其中的文件，再按证据提取、去重、归类、填表及核对的顺序完成工作。没有路径时请用户提供本次出差文件夹；已有明确路径时直接读取，不重复询问。仅处理该文件夹及其相关子目录，不自行合并同级的其他出差资料。

在已授权的报销任务范围内继续填写已知内容，不为每一步重复请求确认。公司、收款人采用上述固定设置；项目、出差目的、税额及银行信息以用户资料或 ERP 现有记录为准。遇到必填且无法确定的事项，集中询问，同时继续可独立完成的整理工作。

只将可复用的入口、字段含义和操作方法沉淀回 skill。票据原件、账号凭据、完整银行账号和单次报销的个人明细保留在当次任务资料中。
