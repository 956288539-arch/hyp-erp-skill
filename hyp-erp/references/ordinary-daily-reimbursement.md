# 普通日常报销

入口：`My HYP → 我的财务 → 普通日常报销`，图片线索 `/images/process/1.jpg`。按本次已确认的部门或职能口径承担日常费用时使用。用途判断来自实际表单，内部制度仍以用户和公司要求为准。先读 [共用操作](form-common.md)。

2026-09-08 已在实际 ERP 临时表单核验费用类型选项、科目/选项、部门级联选择、电子普通发票登记、费用汇总、个人收款行及附件窗口，最后取消表单，未提交审批。

## 1. 主表及报销费用类型

核对标题及“普通日常报销费用清单”。主表有主题、起草人、报销人、报销所在部门、归属公司、报销时间、报销金额、货币、备注，另有 **报销费用类型**。

当前默认“部门费用”，下拉还有行政费用、人资费用、品牌部费用、固定资产、成本费用、合约费用。按本次承担口径选择；未知时集中询问费用类型与承担部门。默认值不等于公司已替本次业务作出判断，各费用类型的审批及内部适用范围未由本次核验确认。

填写主题和备注，说明实际发生日期、事项与费用范围；采用本次用户的公司及个人资料，保留系统报销时间。此表没有出差起止日期。报销金额由明细汇总。

## 2. 费用清单新增

在 **普通日常报销费用清单** 区域点“新增”，打开“新增报销信息”。旧区域“报销科目合并，本框内不再需要填写数据”由系统汇总，不另填。

1. 先选“报销科目”再选其“报销选项”。普通日常科目比项目日常更多，当前另见宣传费、招聘费、租赁费、水电费、固定资产采购等，实际候选依当前页面及权限核对。
2. 实测“办公费”下有文具耗材、电子配件（小额）、打印类耗材、低值易耗品、名片印制费、印刷及物料制作费、印章刻制费、办公费-其他；“市内交通费”下有车费、停车费。按用途与原件选择，不默认第一项。
3. **切换科目会清空原报销选项**，必须重新展开选择。明细科目与主表报销费用类型是两个字段，分别填写。
4. “部门”通过“选择值”打开级联菜单。按 [部门选择](form-common.md#部门级联菜单) 悬停上级、逐层展开，再点击实际承担部门，核对按钮名称。此处不是项目查询框，不用空格回车方法。
5. 填当前行“费用”“摘要”，记录实际发生日期及工作事由，核对进项税和系统计算的成本、代扣偶然所得税金。不同科目、选项或部门分别列行。

此子表没有项目、订单和业务部门字段，不要求用户为普通日常找项目。报销所在部门与费用承担部门不能直接等同。

## 3. 电子发票与明细汇总

电子发票在当前明细选“有”，重新取快照，从右侧“发票信息(进项税与电子发票) → 新建”登记。电子普通发票实测选票类“电子发票”，填价税合计、完整票号及数量；税额与特殊票种按 [共用发票操作](form-common.md#电子发票登记与进项税) 处理。

每张发票点子表“确定”后核对登记行。当前明细所有发票及金额核对完，点 **新增报销信息的确定**。回到主表核对科目、选项、摘要、部门、费用、进项税、代扣与成本。实测主表金额和旧科目区域随明细自动汇总。

## 4. 收款、附件与交接

公司已选且主表有金额后，在“收款信息 → 新增”选择本次收款类型及真实候选，核对银行回填，填付款与冲账并确定。按 [收款信息](form-common.md#收款信息) 处理同名或缺失资料。

主表“上传附件 → 请上传附件”按 [附件操作](form-common.md#附件) 逐份上传原件和证明，确认进度完成并将附件加入主表。

核对 `普通日常费用合计＝主表报销金额＝实付＋冲账合计`，费用类型、承担部门和用途一致。依 [交接要求](form-common.md#完成与交接) 留在未提交页面，不把本次费用类型或承担部门记为所有未来报销的默认值。
