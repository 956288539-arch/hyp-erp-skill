# 项目日常报销

入口：`My HYP → 我的财务 → 项目日常报销`，图片线索 `/images/process/2.jpg`。本次已确认是具体项目的非出差支出时使用，例如因项目事由招待甲方。先读 [共用操作](form-common.md)。

2026-09-08 已在实际 ERP 临时表单核验科目/选项、项目查询回填、电子普通发票登记、明细汇总、个人收款行及附件窗口，最后取消表单，未提交审批。

## 1. 主表

核对标题及“项目日常报销费用清单”。姓名、报销所在部门、归属公司采用当前用户资料；填写主题和备注，保留系统报销时间与适用货币。报销金额由明细汇总，不直接填写。

主题可用“报销人＋事项日期＋项目/事项简称＋项目日常报销”；备注写实际发生日期、项目事由和费用范围。此表没有出差起止日期，也没有普通日常的“报销费用类型”。

## 2. 费用清单新增

在 **项目日常报销费用清单** 区域点“新增”，打开“新增报销信息”。旧区域“报销科目【报销科目合并，本框内不再需要填写数据】”由系统汇总，不另填。

| 子表字段 | 操作 |
| --- | --- |
| 报销科目 | 第一个科目下拉，按已确认用途选。当前见市内交通费、办公费、业务招待费、制作费等。 |
| 报销选项 | 选择科目后再开第二个下拉。实测业务招待费下为住宿费、餐饮费、礼品费；市内交通费下为车费、停车费。 |
| 项目 | 输入关键词、回车、展开候选，点击完整记录。输入关键词不等于选中。 |
| 订单编号、业务部门 | 项目选中后自动回填，核对后继续，不人工猜填。 |
| 费用 | 当前行实际拟报销金额，不在每行重复全单总额。 |
| 进项税、成本、代扣偶然所得税金 | 普通票进项税保持零，成本和代扣由系统计算。专票按共用说明核对，不自行给餐费套税。 |
| 是否有电子发票 | 按原件选择；电子普通发票也选有，并在右侧逐张登记。 |
| 摘要 | 当前行实际发生日期、事由及必要的项目/招待信息，缺失业务信息补问。 |

用户确认“因项目事项请甲方吃饭，未出差”时，可选“业务招待费 → 餐饮费”并选择实际项目；不能仅凭餐饮发票作此分类。

### 项目候选不足

先查明确关键词。未找到时，在项目框执行 **空格 → 回车 → 空格 → 回车** 加载全部项目，随后清空文字，输入关键词、回车、展开并点击真实记录。核对完整项目、订单和业务部门，不能采用查询中临时带出的默认记录。同名或权限问题仍未解决时补问项目，不改走普通报销。

## 3. 发票登记与费用行汇总

1. 明细选“有”后重新取快照，从右侧“发票信息(进项税与电子发票) → 新建”按 [发票操作](form-common.md#电子发票登记与进项税) 逐张填票种、价税合计、票号和数量。
2. 点发票子表“确定”，等待返回明细子表并核对发票行。全部登记后核对费用和税额，点 **新增报销信息的确定**。
3. 选有却未登记实测提示“请在右方面板添加电子发票”。补录实际发票，不为关闭窗口改选无。
4. 回到主表核对项目费用行和报销金额。旧科目区域会自动出现汇总，不重复手填。不同科目、选项或承担项目分别列行，每行可追溯到票据。

项目归属和费用在同一行完成，此类型不另建差旅行程或项目费用分拆表。

## 4. 收款、附件与交接

公司已选、主表有金额后，从“收款信息 → 新增”按 [收款操作](form-common.md#收款信息) 选本次收款记录、核对银行、填写实付及冲账并确定。主表“上传附件”按 [附件操作](form-common.md#附件) 上传原件和证明。

核对 `项目日常费用合计＝主表报销金额＝实付＋冲账合计`，以及每行项目、科目/选项、税额和附件。依 [交接要求](form-common.md#完成与交接) 保留正式任务的未提交表单，由用户本人检查提交。
