# BrowserOS Neo 安装与连接

在首次网页操作缺少环境或连接失败时读取。安装同意规则来自用户要求；已连接的环境直接复用。本流程的完成条件是 Codex 能通过 Neo 打开并读取页面，然后继续原来的邮箱或 ERP 任务。

## 1. 区分安装与连接状态

- 先发现当前可用工具；若有 Neo MCP 工具，按当前工具说明读取标签页列表验证连接。仅工具名称存在不能证明浏览器在线。
- 工具缺失或返回 `browser session not connected` 时，再检查本机应用、安装记录、可执行文件及运行状态。Windows 检查已安装应用或卸载注册表、开始菜单以及用户应用目录；macOS 检查应用目录。不要仅以进程未运行或某一个路径不存在判定未安装。
- 同时识别 `BrowserOS Neo` 与旧名 `BrowserClaw`。[官方说明](https://browseros.com/neo/)确认两者是同一产品；原版 BrowserOS 是另一款可并存的浏览器，不能仅凭名字相似判定 Neo 已就绪。
- 已安装但未运行：启动已有应用。已运行但未连接：查看 Neo cockpit 的 Codex 连接状态，执行第 3 节；不要直接重复安装。
- 无法检查本机时，说明尚不能确认安装状态，询问用户是否已安装及其位置；不要直接宣称缺失。

## 2. 未安装：先获得同意，再执行安装

先确认操作系统、架构、[Neo 官方下载入口](https://browseros.com/neo/)当前提供的匹配安装包及安装方式，形成具体方案。只读核实来源可在询问前完成；安装包下载及安装在同意后进行。

询问示例：

> 未检测到 BrowserOS Neo。本次操作需要它，我计划从官网下载安装适合当前系统的版本，并配置 Codex 连接。是否同意我现在安装部署？

紧接着简短说明询问依据，链接本次实际读取的 `SKILL.md` 并引用“确认未安装时，先询问用户是否同意安装 BrowserOS Neo 并配置 Codex 连接”。收到明确同意再执行；沉默、超时或原任务中的“继续报销”不算安装同意。用户拒绝时继续可独立完成的本地资料整理，说明网页操作尚需此环境。

获得同意后完成以下操作，不仅给用户一个下载链接：

1. 从 Neo 官网下载按钮及其实际指向的官方发布渠道，取得匹配系统和架构的安装包。每次核对当前链接；不要硬编码版本号、猜测包管理器 ID 或使用原版 BrowserOS 安装包替代。
2. 核对文件实际落盘及格式；有官方校验值或系统签名时核对。执行安装程序，按官方说明完成安装。静默参数仅使用已核实的参数；需要界面时使用可用的桌面控制工具，先读取其技能说明。Neo 尚未安装时，允许用本机终端或桌面工具完成这段环境部署。
3. 启动已安装的 Neo，确认应用能正常打开，再执行第 3 节。系统弹窗必须用户操作、平台没有安装包或安装报错时，报告具体步骤和错误，保留已完成状态；不要绕过系统拦截或反复重装。

安装授权覆盖本次浏览器及必要 Codex 连接部署。沿用现有浏览器资料和 Codex 其他配置；额外的数据导入、默认浏览器切换等由用户另行选择。

## 3. 配置 Codex 连接与技能

1. 在 Neo 新标签页的 cockpit / MCP 连接面板，找到 Codex，按当前界面的 `Connect` 流程完成连接。这是 [Neo 官方提供的一键接入方式](https://browseros.com/neo/)。部署阶段尚无 MCP 工具时，使用可用桌面工具操作该面板。
2. 确认当前环境能发现 Neo MCP 工具及配套 `browseros-neo` 技能，并读取技能。旧版名称按已安装版本的官方说明识别。不要把仅安装 `hyp-erp` 当成已安装浏览器或桥接组件。
3. 一键连接不可用时，读取该版本官方提供的 Codex 接入说明；可参考官方维护的 [BrowserClaw Codex 接入仓库](https://github.com/browseros-ai/browserclaw-codex-app)。先核实本机 Codex CLI 帮助与所需运行时，再执行当前受支持的配置方式。不要混用原版 BrowserOS 的连接教程，也不要猜测 MCP 端口；以本机 Neo 面板或官方运行状态文件为准。
4. 修改连接配置前保留原配置备份，仅更新所需条目。配套技能缺失时通过当前官方接入方式补齐，不从第三方复制凭据或整份配置。安装后的工具若需重新加载会话才能出现，记录原任务进度，提示用户完成必要的重新加载后继续；此时只报告“已安装，连接待验证”。

## 4. 验证并返回业务流程

- 按 Neo 技能及当前工具 schema 命名会话，在本任务的新标签页打开本次需要的 ERP 或 QQ 邮箱。
- 读取页面快照，确认地址和实际内容已加载，排除仍停在 `about:blank`、连接错误或空白页。只有实际工具调用及页面读取成功，才报告环境部署完成。
- 环境可用后立即回到用户原任务。网站账号未自动填入或需要扫码、验证码时，保留页面让用户在浏览器内完成，再验证登录；不要要求用户把密码发到聊天里。
- 交付时区分“浏览器安装完成”“MCP 已连接”“页面已验证”和“网站待登录”，只报告已实测的状态。安装或连接受阻时，也报告已完成的本地票据工作及准确的下一步。

来源核对日期：2026-09-07。官网确认了 Neo 下载入口、BrowserClaw 更名与 Codex 一键连接；全新机器上的安装流程尚未实测。安装包和客户端接入方式以执行时的官方说明为准。
