# 霍普 ERP 助手

通过 BrowserOS Neo 从 QQ 邮箱归档差旅票据，或读取已有出差文件夹，整理并填写霍普 ERP 项目差旅报销，完成后由用户本人检查并提交。

## 已支持的流程

- 登录与 `My HYP → 我的财务 → 项目差旅报销` 导航。
- QQ 邮箱检索、PDF 附件下载与去重，按一次出差归档发票、行程单和消费记录。
- 票据去重、费用分类、出差日期与报销总额核对。
- 主表、差旅费用清单、项目归属、电子普通发票登记、收款信息和附件上传。
- 项目栏通过“空格 → 回车 → 空格 → 回车”展开全部项目，再按关键词查找。

已使用真实差旅任务验证至提交前。专票分拆有操作指引，尚无专票实例验证；请假和补打卡流程待补充。

## 安装

1. 安装并连接 BrowserOS Neo，确保 Codex 可以使用它的 MCP 工具及 `browseros-neo` skill。
2. 将本仓库的 `hyp-erp` 文件夹复制到 `~/.codex/skills/`。
3. 在 [SKILL.md](hyp-erp/SKILL.md) 中查看并设置归档根目录、归属公司和收款人；仓库当前保留作者的个人默认值。

详细操作见 [QQ 邮箱取票与归档](hyp-erp/references/qq-invoices.md) 和 [项目差旅报销流程](hyp-erp/references/travel-reimbursement.md)。

## 使用

在 Codex 中提供一次出差的完整票据文件夹、项目名称和出差目的，例如：

```text
使用 $hyp-erp 帮我填写这次差旅报销。
发票文件夹：D:\发票\本次出差
项目：填写本次归属项目
出差目的：填写实际工作事项
填好后提醒我检查，由我提交。
```

一个文件夹代表一次完整出差。登录信息未自动填入时，由用户在 BrowserOS Neo 页面内填写。Skill 会核对费用及附件，并保留当前报销表单供本人提交。

也可以直接提供出差日期和地点，请它从已登录的 QQ 邮箱寻找相关票据。默认归档根目录为 `D:\0-工作\发票`，每次出差使用独立子文件夹。仅要求取票或归档时，到资料整理完成为止。

## 仓库内容

`hyp-erp/SKILL.md` 是技能入口，`hyp-erp/agents/openai.yaml` 提供 Codex 展示信息，`hyp-erp/references/travel-reimbursement.md` 记录已验证的页面操作。

发票原件、银行账号、登录凭据与单次报销明细不随仓库发布。
